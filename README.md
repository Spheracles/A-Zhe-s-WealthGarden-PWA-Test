# 阿哲的財富花園 — 可安裝 PWA v1.1.0

## 本版本定位

這是依據使用者提供的單頁 HTML 展示稿，重製的 **可測試 PWA 基礎版**（不是完整版財務系統，也不是 APK / IPA）。保留四個主要頁籤，採深綠色花園風格、純 HTML/CSS/JavaScript，不需 npm、付費主機或資料庫。

### 已能使用

- Android Chrome / iPhone Safari：透過 HTTPS 網址加入主畫面。
- Service Worker 快取：首次成功連線開啟之後，可在離線狀態載入主要介面（不同瀏覽器可能有儲存清除限制）。
- 記帳：收入、支出及資金移轉分開計算，依月份彙總；紀錄日期、用途、投入時數與心力。
- 痛點轉化：裝置內建規則產生行動靈感，**不是 AI**。
- 本機資料保存、JSON 完整匯出／匯入還原、CSV 記帳匯出、刪除與清空確認。
- 文字使用安全的 `textContent` 渲染，避免使用者輸入經 `innerHTML` 直接執行。

### 尚未實作

- 真實資產負債表、帳戶餘額對帳、被動收入自動計算、投資績效、完整課程知識庫與 AI 模型串接。
- 登入、多裝置同步、雲端備份、端對端加密。
- Android APK / Google Play 上架、iOS IPA / App Store 上架。

⚠ 資料只存在開啟此網站的裝置與瀏覽器儲存空間；**PWA 與一般瀏覽器不一定共用同一資料空間**，跨裝置請使用 JSON 匯出／匯入。清除網站資料、移除 App 或瀏覽器清理都有遺失風險。**不要使用虛構的「淨資產」或「85% 健康度」作為財務決策依據。**

## 用 GitHub Pages 發佈（免指令版）

1. 在 GitHub 建立一個**新的公開儲存庫**，例如 `azhe-wealth-garden`；不要覆蓋舊版財富花園專案。
2. 將此 ZIP **解壓縮後**，把 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest`、`icons` 資料夾內的 PNG 檔案上傳至該儲存庫最外層。ZIP 本身不能直接當成網頁開啟。
3. 開啟儲存庫 **Settings → Pages → Build and deployment → Deploy from a branch**，選 `main` 及 `/(root)`，按 **Save**。
4. 等 GitHub Pages 顯示網址：`https://你的帳號.github.io/儲存庫名稱/`。一定要用 HTTPS 網址，不要用手機直接點開 ZIP 裡的 `index.html`。
5. 在 Android 的 Chrome 開啟該網址，選右上角 `⋮ → 安裝應用程式` 或 `新增至主畫面`（實際名稱依手機／瀏覽器而異）。
6. 在 iPhone 的 Safari 開啟網址，按「分享」→「加入主畫面」，啟用「作為網頁 App 開啟」（若有該選項），再按「加入」。

**升級提醒：** 已裝在手機的舊版 PWA 可能會暫時使用舊快取。重新開啟線上網站，必要時關閉再開 App。發布新程式時，先匯出 JSON 備份；不要任意清除網站資料。

- [ ] 網站四個頁籤都能切換、內容與按鈕可見。
- [ ] 新增 NT$120 支出、NT$500 收入、NT$200 資金移轉；本月收入應為 500、支出 120、收支結餘 380。
- [ ] 新增紀錄後重新整理，紀錄依然存在。
- [ ] 財富分析的支出分類與心力數據會隨記帳改變。
- [ ] 痛點實驗會產生本機建議；重新開啟仍能看到紀錄。
- [ ] 匯出 JSON，刪除一筆資料，再匯入 JSON 確認還原（匯入前先備份）。
- [ ] 匯出 CSV，確認可被試算表開啟。
- [ ] 網頁至少成功開啟一次後，切飛航模式並從主畫面開啟 App。
- [ ] 同一個網址在 Android、iPhone 各測一次；**資料不會自動在兩支手機同步**。

## 本機開發預覽（進階）

在此資料夾執行 `python -m http.server 8000`，於電腦瀏覽 `http://localhost:8000`。**不要**用 `file://` 判定 PWA 是否安裝成功，因為 Service Worker 及安裝要求使用 HTTPS 或 localhost。
